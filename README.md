# Script to enable Nintendo Switch 2 Pro Controller over USB on Steam for macOS
Vibe-coded with Claude. Simply run `bash pro2steam.sh`, and then the controller should show up as a normal Nintendo Switch Pro Controller in Steam controller settings.
